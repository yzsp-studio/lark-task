## 🇨🇳 中文

飞书任务管理技能，负责待办事项与任务清单的全流程操作。它能在会话里直接创建待办任务、查看和更新任务状态、把父任务拆成子任务、按项目组织任务清单、把任务分配给协作成员，并上传任务附件。除人工待办外，它还管理任务智能体：注册或注销智能体、更新智能体主页数据、写入智能体任务记录。内置命令选择与渐进式发现（必读），并按 tasks / tasklists / subtasks / members 四类 API 资源组织能力，让 Agent 知道先查哪个接口再动手。

### ✨ 能做什么

- 创建待办任务并更新状态，随时跟踪任务进度
- 把父任务拆成子任务，颗粒度细到可交付
- 用任务清单（tasklists）按项目归堆，查看任务列表
- 把任务分配给协作成员（members），直接派到人
- 上传任务附件，把文件挂到对应任务上
- 注册/注销任务智能体，更新主页数据并写入任务记录

## 🇬🇧 English

A Lark Tasks skill that runs the whole to-do and task-list workflow in conversation. It creates to-do items, reads and updates task status, splits parent tasks into subtasks, organizes task lists, assigns collaborator members, and uploads task attachments. Beyond human tasks it also manages task agents: registering or unregistering an agent, refreshing its homepage data, and writing agent task records. Command selection and progressive discovery are required reading, and capabilities are organized by four API resources — tasks, tasklists, subtasks, and members.

### ✨ What it does

- Create to-dos and update status to track task progress
- Split a parent task into deliverables-level subtasks
- Group work into task lists per project and browse them
- Assign tasks to collaborator members directly
- Upload attachments and pin files to a task
- Register or unregister task agents, refresh homepage data, write agent task records

- `lark-task` — [`lark-task/SKILL.md`](lark-task/SKILL.md)
